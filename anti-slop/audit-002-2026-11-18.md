## Layout
10. MediumFlexibleTopAppBar with exit-until-collapsed on a screen that barely scrolls (D:123-167): costs about 110 dp. Use a small bar (back, order code) and make the customer name the hero in the body.
11. Bottom bar is three 56 dp buttons in two rows plus messages (about 200 dp). Move Call next to the customer name as an icon button (as on Today). Bottom: [Navigate, tonal] [primary action] in one row.
12. Status is 11sp text. Show a 3-step progress (Assigned, Picked up, On the way) or let the primary button carry it.
13. On the way: show ETA and distance (state has them, Today shows them). PRD 6.3 asks for a preview map with pin and rider position, not built.
14. Optional: swipe-to-confirm for Start delivery only (it starts tracking and exposes the rider's phone to the customer). Not for Picked up or Delivered.

## Navigation
15. System back on History/Account exits the app (no BackHandler in MainScreen). Back from a non-home tab should return to Today.
16. Tracking runs while the rider is on History/Account with no visible sign. Add a compact active-delivery chip (name, ETA) above the toolbar that opens the order.
17. PRD 6.3/6.4: Start delivery should open in-app Navigation SDK; today it hands off to a Google Maps intent, and no NavigationLauncher exists, so eta_seconds/distance_m never get sent. Decide whether in scope.
18. Placeholder tabs (see 3): build a minimal Account now (name, phone, shop, version, Sign out), hide History until it exists.
